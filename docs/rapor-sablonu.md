## 1. Projenin Amaci

Bu projede HTML5, CSS, Bootstrap, JavaScript, Vue ve PHP kullanilarak kisisel tanitim ve teknik becerileri gosteren responsive bir web uygulamasi gelistirilmistir.

## 2. Kullanilan Teknolojiler

- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- Vue 3
- PHP
- TVMaze API

## 4. Teknik Gereksinimlerin Karsilanmasi

- Responsive yapi Bootstrap ile kuruldu.
- Ozel stiller harici CSS dosyasinda tutuldu.
- Iletisim formu Native JavaScript ve Vue ile ayri dogrulandi.
- Login icin istemci tarafi JavaScript ve sunucu tarafi PHP birlikte kullanildi.
- Form verileri PHP ile alinarak duzenli sekilde ekrana yazdirildi.
- API entegrasyonu olarak TVMaze kullanildi.
