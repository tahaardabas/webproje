# Sonradan Doldurulacak Alanlar

Asagidaki alanlar kullanicinin istegiyle yer tutucu olarak birakildi:

## Hakkinda sayfasi

- Kisisel tanitim metni
- Etkinlik / kulup bilgileri
- Sosyal medya linkleri
- Gercek profil fotografi
- Gercek tanitim videosu

## CV sayfasi

- Egitim detaylari
- Teknoloji listesi
- Sertifikalar
- Projeler

## Iletisim sayfasi

- Gercek telefon numarasi
- Gerekirse ek iletisim detaylari

## Teslim sonrasi guncellenmesi gerekenler

- GitHub repo linki
- Canli site linki
- Rapor ekran goruntuleri

## Nereleri degistireceksin?

- Hakkinda metni icin: `index.html`
- CV detaylari icin: `cv.html`
- Iletisim sabit bilgileri icin: `contact.html`
- Login bilgisi degisecekse: `login.php` ve `login-handler.php`
