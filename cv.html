Kariyer Özeti

Bilgisayar mühendisliği alanında eğitimine devam eden, yazılım geliştirme ve web teknolojilerine ilgi duyan bir öğrenciyim. HTML, CSS ve JavaScript gibi temel web teknolojileriyle projeler geliştiriyor, aynı zamanda yazılımın mantıksal yapısını ve problem çözme süreçlerini aktif olarak öğreniyorum. Windows Forms ve .NET tabanlı uygulamalarla masaüstü geliştirme deneyimi kazanırken, GitHub gibi araçlarla versiyon kontrolü pratiği yapıyorum. Kendimi hem frontend hem de genel yazılım geliştirme alanında ilerletmeyi hedefliyorum ve öğrendiğim bilgileri küçük projelerle pekiştirerek sürekli geliştirmeye odaklanıyorum.
